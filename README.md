# Domain Tab Grouper

同じドメインのタブを自動でタブグループにまとめる、個人用の Chrome 拡張機能です（Aside など Chromium 系ブラウザ向け）。

## インストール

1. ブラウザで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

コードを変えたら、同じ画面で拡張機能の再読み込みボタンを押します。

## 動き

- 同じドメインのタブが2個以上（設定で変更可）になると、ドメイン名のグループにまとめます（例: `github.com` → 「github」）
- 同じドメインには毎回同じ色が付きます
- タブで別のサイトに移ると、そのタブは元のグループから外れて、移った先のグループに入ります
- グループのタブが設定数を下回ると、グループを解除します
- ピン留めしたタブと、自分で作ったグループのタブには触りません
- 「サブドメインも同じグループにする」をオンにすると、`mail.google.com` と `docs.google.com` が「google」にまとまります
- 「見ていないグループを折りたたむ」をオンにすると、表示中のタブがあるグループ以外を折りたたみます
- ポップアップの「グループを解除」は、自動でまとめる設定をオフにしてから、この拡張が作ったグループをすべて解除します
